# BlueCurrent Swim School

Interactive demo for swimming class enrollment by neighbourhood and condominium in Singapore.

## Features

- Choose a neighbourhood (Clementi or Bishan) and a condominium.
- Browse the selected venue's example class schedules and seat capacity.
- Enroll example swimmers, join waitlists, remove records, and promote waitlisted swimmers.
- Search and filter enrollment records, export a CSV, or restore the sample data.
- Works as a static website on GitHub Pages without a server or build step.

## Publish with GitHub Pages

1. Create a **public** GitHub repository named `swimming`.
2. Upload `index.html`, `.nojekyll`, and this `README.md` to the repository's `main` branch (root directory).
3. Go to **Settings → Pages**.
4. In **Build and deployment**, choose **Deploy from a branch**.
5. Choose `main`, folder `/(root)`, and click **Save**.
6. Open the website URL shown under GitHub Pages after deployment.

For this repository, the expected URL is `https://teoejn.github.io/swimming/` once Pages is enabled and deployment succeeds.

## Important

All classes, coaches, schedules, and students are fictional. Condo names are real example venues; this demo does not imply the venues currently offer these lessons, or that visitors can use their facilities. Enrollment changes are stored in the visitor's browser when local storage is permitted. There is no shared database, payment processing, or real booking functionality. Do not use this demo to collect actual student information.
